# Novedades

Las novedades son los avisos del equipo de AlfaCore: notas de cada versión, cambios importantes y
comunicados.

## Dónde se ven

- **Campana (barra superior):** cuando hay una novedad nueva, aparece en la campana con un punto
  azul. Al tocarla se abre la novedad completa.
- **Página Novedades:** desde la campana, **Ver todas las novedades**. Ahí quedan guardadas todas,
  la más nueva arriba. Cada una se abre y se cierra tocando su título, y hay botones para
  **Abrir todas** y **Cerrar todas**.

Abrir una novedad la marca como leída: deja de aparecer en la campana, pero sigue guardada en la
página Novedades.

## Cómo se escriben (Informes → Novedades)

1. **Manual** o **Boletín patch** crea un borrador con un ejemplo.
2. En **Detalles** se escribe el contenido. Los botones de arriba y el menú de comandos (⋮) suman:
   títulos, listas, llamados (información, éxito, atención), imágenes y capturas, botones y dos
   bloques pensados para notas de versión:
   - **Antes / Después:** dos columnas para mostrar cómo era y cómo queda.
   - **Tarjetas con ícono:** tres puntos destacados, cada uno con su ícono.
3. En **Ajustes** van el título, la versión, el color y el ícono.
4. **Publicar ahora** (o **Programar** para una fecha): todos los usuarios reciben el aviso en la
   campana.

**Vista previa** muestra cómo la va a ver el usuario antes de publicarla.
