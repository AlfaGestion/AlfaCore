El manual funcional del módulo se encuentra en:

- [src/AlfaCore/Docs/manual_auditoria_usuarios.md](../src/AlfaCore/Docs/manual_auditoria_usuarios.md)

## Criterio

Los manuales de usuario que la aplicación puede consumir o embeber se mantienen en `src/AlfaCore/Docs/`.
La carpeta `docs/` queda reservada para:

- documentación técnica
- reglas del proyecto
- catálogo
- puentes o accesos directos desde el repositorio
