# Carga de Viajes - Nota de UI

Fecha: 2026-06-16

## Cambio

- Se ajustó la presentación del módulo para que no muestre códigos internos en tarifas, reportes y liquidaciones.
- Los autocompletados y campos visibles ahora muestran solo descripciones o nombres, con fallback al código cuando no existe texto descriptivo.
- La lógica interna de búsqueda, selección y guardado sigue usando los identificadores reales.
